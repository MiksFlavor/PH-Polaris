# POLARIS

POLARIS is a starter frontend for a future Philippine political activity visualization platform. This repository currently contains only a small, public-repository-safe dashboard foundation built with mock data.

## Current Status

- Frontend for the moment
- Mock data for the moment for test
- Interactive regional visualization foundation
- No scraping, no backend, no authentication, no database, and no LLM integration yet

## Tech Stack

- React
- JavaScript
- Vite
- Bootstrap

## Future Note

This starter intentionally stays on your current stack for now. Replace the frontend stack later only when you are ready to move to the recommended tools.

## Run Locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Build for production:

   ```bash
   npm run build
   ```

## Notes

- The current map is a schematic starter visualization using mock regional values.
- All mock values are centralized in `src/data/mockData.js`.
- No secrets or private datasets are included.
